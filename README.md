# 모아모아

아이가 좋아하는 분야마다 한 권의 도감을 만들고, 그림·사진과 낱장 지식을 카드로 모으는 태블릿 중심 웹앱입니다. GitHub Pages 주소에 접속해 사용하며 Android 앱 패키징과 계정 동기화는 포함하지 않습니다.

## 실행

```bash
npm install
npm run dev
```

## 확인

```bash
npm test
npm run build
```

## 데이터

- 책, 카드, 작성 중인 초안은 브라우저 IndexedDB에 저장됩니다.
- 도감 안의 `카드 전체 받기`로 그 도감의 모든 카드를 PNG가 담긴 ZIP 파일로 저장할 수 있습니다.
- 상단 `데이터 보관`에서 JSON 백업과 복원을 보조 기능으로 사용할 수 있습니다.
- 같은 주소에서 이전 초안의 `localStorage` 키 `dogam:v1`을 발견하면 첫 실행 때 한 번 가져옵니다.
- 계정, 클라우드 동기화, AI 사실 판정, Obsidian 저장은 포함하지 않습니다.
